- Report line: `[rn-material-symbols] rounded 8 icons · 5.4 KB · aliases 1 · safelist 1 · 2 files (8ms)` (iOS; 1ms on Android).
- Inputs: `cd example && npx react-native bundle --platform {ios,android} --dev false --entry-file index.js --bundle-output /tmp/rnms.{ios,android}.js --assets-dest /tmp/rnms-assets --reset-cache`, then `node scripts/assert-bundle.mjs <bundle>`, run right after `pnpm build`.
- Not covered: `--dev true` bundles (watch path), Android device, a release binary plus a real CodePush deployment, the bundle after Hermes bytecode compilation, a single React instance at runtime (the bundle markers cannot prove it).
- Assertion method: collect every string literal (`"…"`, `'…'`) in the bundle into a set, match it against the `d`/`f` path strings of `icons/{rounded,outlined,sharp}/*.js` to get the set of icon names in the bundle, and require it to equal the expected 8 exactly (missing or extra both fail). Alias names that share a glyph (`chevron_forward` and `keyboard_arrow_right` share the path of `chevron_right`) count only toward the expected name that owns them. Forbidden names (`devices_wearables`, `backspace`, `share`) are checked separately.
- Names-list hit limit: the initial limit was 50, but a correct bundle measured 54, because React Native's own strings (`ios`, `add`, `close`, `style`, `padding` …) and 8 app strings overlap icon names. A real leak shows 3,927, so the limit is 200.
- Negative controls (run): (1) appending the `d` of `outlined/star` to a copy of the iOS bundle fails with `unexpected star`, exit 1; (2) appending the full name array fails with names-list hits 3927, `name list leaked`.
- Not verified: the `react.production` marker appears twice in the bundle, but module boundaries were not checked, so a single React instance remains unconfirmed.
